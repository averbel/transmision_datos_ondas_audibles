SpaceWases

Texto convertido en tonos audibles. Un altavoz emite, un micrófono escucha y la trama se reconstruye con Reed-Solomon.

48 kHz · MFSK · RS(255)

Enviar

Escribe el mensaje, elige un perfil y emite la señal. También puedes guardarla como WAV.

Con clave el mensaje se cifra y se autentica. Usa una frase larga: una clave corta se puede adivinar por fuerza bruta. La clave no sale de tu navegador.

Recibir

Escucha con el micrófono o abre un WAV. La clave debe coincidir con la usada al emitir.

Evita que alguien grabe un mensaje y lo reproduzca después. Exige que la hora de ambos dispositivos esté en hora (tolerancia de 2 minutos). No se aplica a los WAV cargados.

    Sin clave el mensaje viaja en claro y cualquiera puede fabricar tramas válidas. Con clave se cifra y se autentica, pero la construcción es propia y no ha sido auditada: no la uses para información sensible. Cualquier micrófono cercano recibe la señal.
